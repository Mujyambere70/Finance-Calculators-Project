About CalcWise

From a console program to a full web application.

The project

CalcWise started as the Finance Calculator capstone project of the HyperionDev Software Engineering Bootcamp: a Python console program with two calculators - investment (simple or compound interest) and bond (home loan) repayment.

It was rebuilt as a web application with five calculators, live results, charts, full schedules, saved calculations, share links, CSV export and print. The original formulas are still used and tested:

  • A = P(1 + r·t) - simple interest
  • A = P(1 + r)t - compound interest
  • x = i·P / (1 − (1 + i)−n) - bond repayment

Built with Python, Flask, SQLite, Jinja2, HTML, CSS and JavaScript (charts drawn as SVG, no libraries).
