About passport numbers

  • Gives the number format only - for testing booking, visa or registration forms. It is not a document and is not valid for travel.
  • {{ passport_known }} countries use their published format (USA 9 digits, Germany "C" + 8, China "E" + 8, India 1 letter + 7 digits …), some are marked approximate, and the rest use the general international format (up to 9 letters and digits, ICAO 9303).
  • A random number can match a real passport by chance - never use one as if it were real.
